# `data/`

| File | Purpose |
|---|---|
| `skills.json` | The configurable skill dictionary used by the skill extractor. Edit it to adapt the system to another domain - no code changes needed. |
| `sample_resume.txt` | A fictional resume used for demos and tests. |
| `sample_resume.pdf` | The same resume as a PDF, generated by `scripts/generate_sample_pdf.py`. Use it to demo the upload flow. |
| `sample_job_description.txt` | A fictional AI/ML internship job description. |

**The sample resume is entirely fictional.** It contains no real personal data.

**Uploaded resumes are never written here.** The application processes uploads in
memory only - see the privacy section of the README.
